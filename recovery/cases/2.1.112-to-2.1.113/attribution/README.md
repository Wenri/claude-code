# Generated-source attribution

The matching 2.1.88 bundle/source-map pair supplies exact ownership only for
the historical baseline. It is never used as a target-byte oracle. Stable
literal anchors then partition the exact 2.1.113 analyzable entry point and
rank candidate historical owners.

All 12,986,752 target UTF-16 code units are accounted for. The inventory
contains 4,756 historical source-owner rows, 4,986 target initializer regions,
and 30,163 exhaustive target partitions. Three partitions (2,181 code units)
remain conservatively unresolved; their bytes are still present in the exact
target and the complete structural/readable ledgers.

The 2.1.113 Bun build changed minifier parameter names in its module wrapper
helpers. The attribution tool now discovers arbitrary valid JavaScript
parameter names and checks their internal back-reference structure instead of
assuming the older `q,K` spelling.

No target source map exists. This report therefore does not claim erased
TypeScript spelling, comments, formatting, types, or exact authored module
boundaries.
